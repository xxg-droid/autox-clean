# AutoX 干净版使用说明

## 这是什么

AutoX（AutoX.js）是一个安卓手机自动化工具：用 JavaScript 脚本控制手机，自动完成重复操作，比如自动点击、填写、滑动屏幕。

这个版本是基于官方开源源码（GitHub automan-bot/AutoX，标签 6.5.5.10，2024 年 7 月 13 日发布）重新编译的干净版。源码经过检查，按下面的清单做了清理，原始源码没有动过，改动记录见 `build/CHANGES.md`。

## 相对原版改了什么

### 删除的东西

- 原作者的联系方式：关于页里的 QQ 群、邮箱、GitHub 链接，分享文案改为中性文字
- 统计与上报：Flurry 统计、腾讯 Bugly 崩溃上报、腾讯 TBS 浏览器内核（改用系统 WebView）
- 论坛、登录、社区、市场：相关界面和后端代码全部删除，不再需要登录
- VS Code 调试通道：电脑远程下发脚本的通道已删除
- 打包功能的远程控制：打包模块里连接别人服务器、上报 IMEI、接受远程脚本的部分全部删除；打包功能本身保留，打出来的安装包是干净的独立运行包
- 休眠的 IMEI 上报接口：一个没人调用的上报接口，已删除
- 设备 ID 读取接口：脚本读取 IMEI、Android ID 的接口已删除
- 更新检查：不再检查更新，也不会提示升级回原版
- 内置示例脚本、分享和评分入口

### 精简的权限

声明的权限从 185 项减到 76 项。删除的主要有：短信、通讯录、通话记录、后台定位、录音、相机、传感器、账户等与自动化无关的权限。

保留的权限：无障碍服务、悬浮窗、通知监听、存储、网络、前台服务、忽略电池优化、自启、震动、唤醒锁、定位（仅声明，运行时需用户授权）。

### 加固

- 禁止明文网络流量，禁止应用数据备份导出。

### 保留的功能

脚本运行、无障碍操作、悬浮窗、代码编辑器、定时任务、OCR 文字识别、找图找色、打包功能、脚本动态加载。

### 2026-11-09 更新（fix1，build26）

- 修了文件访问权限：安卓 11 以上的手机上，旧版只认读写存储权限，会一直提示“请开启外部存储权限”，脚本列表和添加脚本用不了；新版改为认“所有文件访问权限”，打开后会引导你去开，开一次就好。
- 删了底部导航的“文档”页（原来点进去是空页），现在底部只剩首页和管理。
- 全 App 字号放大到 1.2 倍。

- 32 位版（armeabi-v7a）：新旧手机通用，老手机和新手机都能装

  - SHA256：`1055d58d624832de046547c394e170cbc2443bd3950cf5523b960f7ab3096ca2`
- 64 位版（arm64-v8a）：只能装在 64 位的新手机上

  - SHA256：`ff074c3e783b70de2709edbbcb7d8e088549dae20886df759e352e1d8b950740`

## 安装步骤

1. 如果你现在装的是原版或第三方改版，**先卸载再装**（签名不同，无法直接覆盖安装）。如果已经装了本干净版的 build25，直接安装新版覆盖就行，不用卸载。
2. 把安装包传到手机上，点开安装。
3. 允许“未知来源安装”。三星手机如果开了“自动拦截”，需要先关掉或在提示里允许安装；Play 保护如果弹出警告，选“仍要安装”。
4. 打开应用，按提示开权限：
   - 无障碍服务：必需，没有它脚本点不了屏幕
   - 悬浮窗：必需，跑脚本时的控制窗口
   - 电池设为“不受限制”：防止手机后台杀掉应用
   - 所有文件访问权限：必需，没有它脚本列表和添加脚本用不了；新版打开后会引导你去开，也可以手动去设置 → 应用 → 右上角三个点 → 特殊访问权限 → 所有文件访问权限 → AutoX → 允许
   - 安卓 13、14、15 的手机：去设置里允许“受限设置”，不然无障碍开不了
5. 新手机第一次打开时如果提示“此应用是为旧版 Android 打造”，点继续即可。

## 使用方法

1. 把脚本文件导入应用（应用内导入，或把脚本文件放到手机存储后在应用里打开）。
2. 打开要操作的 App，到相应界面。
3. 在 AutoX 里运行脚本，屏幕上出现悬浮窗，可以随时停止。
4. 定时任务：在应用里设好时间和脚本，到点自动跑。

## 注意事项

- **没有自动更新**。更新检查已删除，以后有新版需要手动换安装包。
- **崩溃不再上报**。出问题只在手机本地显示错误报告，不会发到任何服务器。
- **只运行可信的脚本**。脚本能操作手机，陌生人给的脚本不要跑。
